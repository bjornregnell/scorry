# Scorry: correlation and summary statistics

Correlation, mean and other statistics in a single-page web app written in [Scala](https://scala-lang.org/) with [Laminar](https://laminar.dev/) using [Claude Code](https://en.wikipedia.org/wiki/Claude_(language_model)#Claude_Code). It is built with [sbt](https://www.scala-sbt.org/) and the [ScalaJS](https://www.scala-js.org/) code is compiled by sbt and hot-reloaded to localhost using [Vite](https://www.scala-js.org/doc/tutorial/scalajs-vite.html).

Try it out here: [bjornregnell.github.io/scorry/](https://bjornregnell.github.io/scorry/)
